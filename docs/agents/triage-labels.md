# Triage Labels

skills 使用五种 canonical triage roles；此文件将这些 roles 映射到本仓库 issue tracker 中实际使用的 label 字符串。

| mattpocock/skills 中的 label | 本仓库 tracker 中的 label | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer 需要评估此 issue |
| `needs-info` | `needs-info` | 等待 reporter 提供更多信息 |
| `ready-for-agent` | `ready-for-agent` | 信息完整，可交由 AFK agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当 skill 提及某个 role 时，使用表格中对应的 label 字符串。若本仓库采用其他标签词汇，修改右侧 label 列即可。
